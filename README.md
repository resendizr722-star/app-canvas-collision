# 🎨 Simulación de Círculos en Canvas

Aplicación web interactiva desarrollada con **HTML, CSS y JavaScript** que demuestra el uso de la API de **Canvas 2D** para crear animaciones dinámicas y visualmente atractivas.

El proyecto incluye múltiples simulaciones de círculos con comportamientos distintos como movimiento, colisión y rebote.

---

## 🚀 Características

- 🎯 Animación en tiempo real con `requestAnimationFrame`
- 🎲 Movimiento aleatorio y natural de partículas
- 💥 Detección de colisiones entre círculos
- 🔁 Rebote dinámico entre objetos
- 🎨 Estilos visuales modernos (neón, glow, gradientes)
- 🎚 Control interactivo de cantidad de círculos
- 📱 Interfaz responsiva con Bootstrap
- ⚡ Optimización de rendimiento y animaciones

---

## 🧠 Simulaciones

### 🟢 Movimiento
Círculos que se desplazan libremente dentro del canvas y rebotan en los bordes.

### 🟡 Colisión
Círculos que cambian de color cuando se tocan o se traslapan.

### 🔴 Rebote
Círculos que rebotan entre sí intercambiando velocidad al colisionar, simulando comportamiento físico.

---

## 🛠 Tecnologías utilizadas

- HTML5  
- CSS3 (animaciones, gradientes, efectos glow)  
- JavaScript (Canvas API)  
- Bootstrap 5
